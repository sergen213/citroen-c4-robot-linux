## Address identity and confidence

Addresses below are Ghidra virtual addresses, **not file offsets**. Always pair an address with the exact binary SHA-256 and analysis image. A name discovered by Ghidra is not evidence that gameplay semantics were recovered. `CONFIRMED` describes the stated import/entry/call fact; `HIGH CONFIDENCE` describes an interpretation supported by multiple clues; `HYPOTHESIS` names a candidate; `UNKNOWN` names an unrecovered responsibility.

Persistent analysis: `work/ghidra/CitroenC4Robot.gpr`. Hash-scoped evidence directory: `work/reports/ghidra/<basename>_<SHA12>/`. Full function/call/import/export inventories remain in their TSVs; this table is the maintained semantic subset, not an arbitrary claim of complete recovery. Do not distribute original decompiler output.
