# Reverse engineering and initial porting report

## Evidence rules

`CONFIRMED`: directly present in measured binary/tool/source evidence. `HIGH CONFIDENCE`: corroborated interpretation, not full behavioral equivalence. `HYPOTHESIS`: candidate to investigate. `UNKNOWN`: not yet recovered. Ghidra pseudocode is an analysis aid, not trustworthy source; verify disassembly, calling conventions, data layouts, imports and runtime observations before reconstructing behavior.

Original installers, executables and assets are never modified in place. Do not bypass DRM/license protections. Static unpacking of an ordinary executable packer is a derived analysis copy, not permission to circumvent access controls. No original assets or pseudocode payloads belong in native release artifacts.
